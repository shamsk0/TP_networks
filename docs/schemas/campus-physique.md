# Vue physique CC-A / CC-B

Cette vue ajoute au schéma du chapitre les deux locaux techniques, les deux routes de fibre et l'alimentation de chaque cœur.
Hypothèse (pas de plan de câblage réel) : route 1 par la galerie technique nord, route 2 par la façade extérieure sud.
Cause commune restante : les deux routes se rejoignent dans la chambre de tirage sous la cour, donc une seule coupure peut couper les deux fibres.
Alimentation : un UPS par cœur (UPS A, UPS B), donc pas de cause commune électrique.
